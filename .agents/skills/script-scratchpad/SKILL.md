## Using the Scratchpad

Sometimes it is neccessary to write code that is not part of the OpenArc codebase AND not owned by any of it's patterns or abstractions. 

Use `.scratchpad` for this work. It is a `.gitignored` place for you to explore ideas, run tests

## Leaving the Sandbox

Code that enters `.scratchpad` should not leave without

- Discussing with the user.
- A concrete action plan approved by the user.
